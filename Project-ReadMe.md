# Personal Portfolio Website

## Overview

This project is a **fully responsive** personal portfolio website designed to showcase my skills, experience and projects as a web programming student. Using the knowledge gained from my coursework, I have created a site to best practices in **semantic HTML, accessibility, mobile-first CSS design and Tailwind CSS**.

## Features

- **Semantic HTML:** All components follow best practices for accessibility and readability.
- **Mobile-First Design:** The CSS layout prioritises mobile screens and scales up for desktop layout.
- **Responsive Layout:** Tailwind CSS, Flexbox and CSS Grid ensure adaptability.
- **Dynamic Elements:** JavaScript dynamic elements for enhanced user experience.

## Pages

- **Home Page**: A welcoming introduction with highlights of my journey as a developer.
- **About Page**: Details about my background, experience and passion for web development.
- **Resume Page**: A structured presentation of my skills and work experience.
- **Projects Page**: A showcase of my past web development projects with detailed descriptions.
- **Sample Project Pages**: Detail views of individual projects with code samples and live Api integration demos.
- **Contact Page**: A contact form for users to send me message, integrated with backend processing.

## Technologies Used

- **HTML5 & CSS3**: Clean, accessible and validated code structure.
- **Tailwind CSS**: Streamlined styling and responsiveness.
- **JavaScript (ES6+):** DOM manipulation, form validation and interactivity.
- **Web Storage API**: LocalStorage for saving user preferences.
- **Async & Await**: Handling API requests efficiently.
- **FTP**: Deployment and file transfers.

## Deployment & Hosting

The website will be deployed using **FTP** to a hosting service, ensuring proper accessibility and security. The site is optimised to be responsive and functional across modern browsers.
